# Gridnote MVP Release Notes

## Included

- Local TXT and non-DRM EPUB import and reading.
- UTF-8, UTF-16, GB18030, and EPUB spine/TOC support.
- Reading progress persistence for text documents.
- Searchable local library with aliases, source status, removal, and re-linking.
- Original spreadsheet-style office shell with minimal editing and persistence.
- Reading excerpts projected into the office Notes column.
- Focused workspace shortcut, Escape return, and optional deactivation-to-office behavior.
- Safe disguise window titles and per-book alias/workbook/sheet metadata.
- Reader font size, line spacing, and system/paper/dark themes.
- Menu bar controls and a movable floating reader with character-based pagination.
- Offline fixtures, automated tests, performance smoke checks, and release documentation.

## Not Included

- PDF, full Excel compatibility, formulas, XLSX, DRM removal, OCR, cloud sync, networking, accounts, telemetry, or a global system shortcut.

See `KNOWN_LIMITATIONS.md` for detailed technical boundaries.
